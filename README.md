# CodeAlpha Data Analytics Internship

This repository contains my projects completed as part of the **CodeAlpha Data Analytics Internship**.

The projects focus on practical applications of Python for **Web Scraping, Exploratory Data Analysis (EDA), and Data Visualization**.

---

## 📌 Tasks Completed

### Task 1: Web Scraping

**Notebook:** `Task1_WebScraping.ipynb`

In this task, I collected job-related information from a practice website using Python.

**Libraries used:**
* Requests
* BeautifulSoup
* Pandas

**The scraped data was saved as:**
`scraped_job_data.csv`

**The dataset contains:**
* Job Title
* Company
* Location
* Date Posted

---

### Task 2: Exploratory Data Analysis (EDA)

**Notebook:** `EDA_Task2.ipynb`

In this task, I explored and analyzed the scraped dataset to understand its structure, patterns, and characteristics.

**The analysis includes:**
* Dataset structure and dimensions
* Missing-value analysis
* Duplicate-value analysis
* Unique companies
* Job locations
* Common job titles
* Posting dates
* Summary statistics

**Libraries used:**
* Pandas
* Matplotlib

---

### Task 3: Data Visualization

**Notebook:** `Task-3.ipynb`

In this task, I created visualizations to present the findings from the job dataset in an easy-to-understand format.

**The visualizations include:**
* Top hiring companies
* Most common job locations
* Most common job titles
* Job-posting date analysis

**Libraries used:**
* Pandas
* Matplotlib
* Seaborn
